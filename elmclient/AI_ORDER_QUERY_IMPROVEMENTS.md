# AI客服订单查询功能优化说明

## 🎯 问题描述

原来的AI客服在处理订单查询时存在以下问题：
1. 用户询问"查6号订单"时，AI给出通用指导而不是具体订单信息
2. 当用户有多个订单时，只能查看最后一个订单
3. 无法区分用户是想查看特定订单还是所有订单

## ✅ 优化内容

### 1. **订单号提取功能增强**

**支持的查询方式**：
- `6号订单` / `订单6`
- `订单号：6` / `订单号6`
- `订单ID：6`
- `第6个订单` / `编号6的订单`
- `查询6号` / `查一下6号`
- `帮我查一下6`

**支持的通用查询**：
- `我的订单` / `我的所有订单`
- `订单状态` / `订单情况`
- `外卖状态` / `我的外卖`
- `订单列表` / `全部订单`

### 2. **智能查询逻辑**

```java
if (!extractedOrderIds.isEmpty()) {
    // 用户指定了具体订单号 → 查询特定订单
    enhancedMessage.append("\n\n您查询的订单信息：\n");
    for (Long orderId : extractedOrderIds) {
        Order order = knowledgeBaseUtil.getOrderById(orderId);
        if (order != null && order.getCustomerId().equals(request.getUserId())) {
            enhancedMessage.append("- ").append(knowledgeBaseUtil.formatOrderInfo(order)).append("\n");
        } else {
            enhancedMessage.append("- 订单").append(orderId).append("：未找到或不属于您\n");
        }
    }
} else {
    // 用户没有指定订单号 → 显示最近的多个订单
    List<Order> recentOrders = knowledgeBaseUtil.getRecentOrdersByUserId(request.getUserId(), 5);
    if (!recentOrders.isEmpty()) {
        enhancedMessage.append("\n\n您的最近订单信息：\n");
        for (Order order : recentOrders) {
            enhancedMessage.append("- ").append(knowledgeBaseUtil.formatOrderInfo(order)).append("\n");
        }
    }
}
```

### 3. **订单信息格式优化**

**新的订单显示格式**：
```
订单号：6，状态：配送中 🚚，总金额：58.50元，下单时间：2025-09-24 10:30:00，商家：川味小厨
```

**状态图标**：
- 待支付 💰
- 已支付 ✅  
- 配送中 🚚
- 已完成 ✨
- 已取消 ❌

### 4. **AI提示词优化**

增加了专门的订单查询处理原则：
- 优先使用提供的实际订单数据
- 区分具体订单查询 vs 通用订单查询
- 支持多订单的分类介绍
- 只有在没有具体数据时才给出操作指导

### 5. **多订单支持**

- **特定订单**：`查6号订单` → 返回订单6的具体信息
- **所有订单**：`我的订单状态` → 返回最近5个订单的信息
- **权限检查**：只能查看属于自己的订单
- **友好提示**：超过5个订单时提示去个人中心查看更多

## 🔧 技术实现

### 关键方法

1. **extractOrderIds()** - 从用户消息中提取订单号
2. **getRecentOrdersByUserId()** - 获取用户的多个最近订单
3. **formatOrderInfo()** - 格式化订单信息显示
4. **containsOrderKeywords()** - 检测订单相关关键词

### 数据流程

```
用户输入 → 关键词检测 → 订单号提取 → 数据库查询 → 格式化输出 → AI回复
```
