# 🤖 可拖拽AI客服使用指南

## 🎯 功能概述

AI客服现在支持**自由拖拽**功能，用户可以将小饿AI放置在屏幕的任意位置，提供更个性化的交互体验。

## ✨ 主要特性

### 🖱️ 拖拽操作
- **鼠标拖拽**：点击聊天窗口头部，按住鼠标左键即可拖拽
- **触摸拖拽**：移动设备上支持手指触摸拖拽
- **视觉反馈**：拖拽时头部背景会变深，显示拖拽状态

### 💾 位置记忆
- 用户拖拽后的位置会自动保存到浏览器本地存储
- 刷新页面或重新访问时，AI客服会出现在上次的位置
- 支持跨会话的位置持久化

### 📏 智能边界
- 自动检测屏幕边界，防止AI客服移出可视区域
- 窗口大小变化时自动调整位置
- 确保聊天窗口始终完全可见

### 📱 响应式设计
- 适配桌面端和移动端
- 不同屏幕尺寸下的优化显示
- 触摸友好的交互设计

## 🚀 使用方法

### 基本拖拽
1. 找到页面上的"小饿AI"按钮
2. 点击打开AI客服聊天窗口
3. 将鼠标移到聊天窗口**头部**（显示"小饿AI客服"的区域）
4. 看到光标变为移动图标时，按住鼠标左键
5. 拖拽到目标位置后松开鼠标

### 移动端操作
1. 打开AI客服聊天窗口
2. 用手指按住聊天窗口头部
3. 拖拽到目标位置后松开手指

### 位置重置
如果需要重置到默认位置：
```javascript
// 在浏览器控制台执行
localStorage.removeItem('ai-chatbot-position')
// 然后刷新页面
```

## 🔧 技术实现

### 核心功能
- **Vue 3 Composition API**：响应式拖拽状态管理
- **事件处理**：支持鼠标和触摸事件
- **位置计算**：实时边界检测和约束
- **数据持久化**：localStorage存储位置信息

### 性能优化
- 拖拽时禁用CSS过渡动画，减少延迟
- 事件节流避免过度渲染
- 智能边界计算减少不必要的位置调整

## 📊 配置选项

### 默认位置设置
```javascript
const setDefaultPosition = () => {
  const windowWidth = window.innerWidth
  const windowHeight = window.innerHeight
  position.value = {
    x: windowWidth - 420,  // 距离右边420px
    y: windowHeight - 150  // 距离底部150px
  }
}
```

## 🐛 常见问题

### Q: 拖拽后AI客服位置不正确？
**A:** 检查浏览器窗口大小，系统会自动调整到安全区域。可以清除localStorage重置位置。

### Q: 移动端拖拽不响应？
**A:** 确保在聊天头部区域进行触摸操作，避免在按钮或其他交互元素上开始拖拽。

### Q: 拖拽时页面滚动？
**A:** 系统已禁用拖拽时的默认行为，如果仍有问题，可能是浏览器兼容性问题。

### Q: 位置记忆失效？
**A:** 检查浏览器是否禁用了localStorage，或者是否处于隐私/无痕模式。
